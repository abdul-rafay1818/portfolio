# Abdul Rafay — Developer Portfolio

A sleek, ultra-minimal, high-contrast monochrome personal portfolio website designed for **Abdul Rafay** (Python Developer in Progress | AI & Machine Learning Aspirant).

---

## ⚡ Features

- **Monochrome & Clean**: Engineered with a pure black-and-white editorial aesthetic with zero visual clutter.
- **Fast & Lightweight**: Pure HTML5, modular CSS3, and vanilla JavaScript with 0 external heavy frameworks.
- **Mobile First & Fully Responsive**: Seamless experience on smartphones, tablets, and wide desktop screens.
- **Accessible & Semantic**: Accessible ARIA labels, semantic landmark tags, and support for `prefers-reduced-motion`.
- **Organized Sections**:
  - **Hero**: Developer badge, high-contrast intro, clear CTAs, and a Python code visual.
  - **About Me**: Background, educational status (Class 12 in Pakistan), and career targets.
  - **Skills & Technologies**: Categorized into *Currently Learning* and *Roadmap / Next Up*.
  - **Selected Projects**: Cards for *FinTrack*, *Jarvis*, and *Python File Manager*.
  - **Learning Journey**: 12-milestone horizontal & vertical roadmap.
  - **Contact**: GitHub, LinkedIn, and Email channels.
  - **Footer**: Clean copyright and smooth back-to-top shortcut.

## 🛠️ How to Customize

1. **Update Social Links & Email**:
   - Open `index.html` and search for `https://github.com/abdul-rafay1818`, `https://www.linkedin.com/in/abdul-rafay-9975a0426/`, or `contact@abdulrafay.dev`.
   - Replace them with your actual GitHub profile, LinkedIn profile, and email address.

2. **Add or Edit Projects**:
   - In `index.html`, locate the `<section class="section" id="projects">` section.
   - Edit the project titles, descriptions, and add your actual repository links in the `<a href="...">` tags.

3. **Update Roadmap Stages**:
   - In `index.html`, locate the `<section class="section" id="journey">` section.
   - As you complete new milestones, switch a step's class from `is-upcoming` or `is-current` to `is-completed`.

## 🚀 Deployment Options

### Option 1: GitHub Pages (Recommended)
1. Push your repository to GitHub.
2. Go to **Repository Settings** &rarr; **Pages**.
3. Under **Branch**, select `main` (or `master`) and `/root`, then click **Save**.
4. Your portfolio will be live at `https://<your-username>.github.io/<repo-name>/`.

### Option 2: Vercel or Netlify
1. Connect your GitHub repository to [Vercel](https://vercel.com) or [Netlify](https://www.netlify.com).
2. Since this is a static site, no build command is needed. Click **Deploy**.
